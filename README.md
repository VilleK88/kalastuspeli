# Kalastuspeli

Unity fishing game in C# using modular systems for gameplay, UI, NPC behavior, map features, and data-driven content.

## Overview
This project is a full Unity-based fishing game featuring:
- Modular gameplay systems
- NPC behavior and interactions
- UI and game state management
- Map-based features (Mapbox integration)
- ScriptableObject-driven content

## Key Features
- Player fishing mechanics and bait system
- NPC interaction system
- Waypoint and marker system
- Modular UI architecture
- Map-based gameplay elements

## Tech Stack
- Unity (C#)
- ScriptableObjects
- Mapbox SDK
